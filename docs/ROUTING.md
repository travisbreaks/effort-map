# The twelve starting points

Generated from [the map data](../data/map.json). Travis’s September 2026 field study, not a model benchmark or a universal recommendation. Alternatives are equal starting points. No condition recorded means the original case did not supply one.

## Dictated notes, capture, summaries

**Environment:** ChatGPT in the browser and on my phone

**Start:** GPT-5.6 Sol · Low or GPT-5.6 Sol · Medium

The priority is faithful capture, not unsolicited analysis. Astra Light is fine if it is already selected.

**Step up or change:** No condition recorded.

**Step down:** No condition recorded.

## Conversation and thinking aloud

**Environment:** ChatGPT in the browser and on my phone

**Start:** GPT-5.6 Sol · High

Sol carries ordinary conversation well and keeps the conversational and editorial character I like.

**Step up or change:** GPT-6 Astra · Medium: when another analytical approach or stronger constraint tracking would help.

**Step down:** No condition recorded.

## Comparing tools, untangling questions

**Environment:** ChatGPT in the browser and on my phone

**Start:** GPT-6 Astra · Medium

Medium is Astra’s broad analytical band: quality and judgment without paying for High on every question.

**Step up or change:** GPT-6 Astra · High: when important tradeoffs or contradictory evidence are being flattened.

**Step down:** No condition recorded.

## Serious research and analysis

**Environment:** ChatGPT in the browser and on my phone

**Start:** GPT-6 Astra · High

Source quality still matters more than the label.

**Step up or change:** GPT-6 Astra · Extra high: for unusually difficult synthesis, calculations, or verification.

**Step down:** No condition recorded.

## Art direction and reference analysis

**Environment:** ChatGPT in the browser and on my phone

**Start:** GPT-5.6 Sol · High or GPT-6 Astra · Medium

Image concepts, Suno direction, reference analysis. Higher effort does not select a better renderer and does not guarantee taste.

**Step up or change:** one rung up on the model in use when many creative constraints interact, or repeated attempts drift.

**Step down:** No condition recorded.

## Small diffs and explanations

**Environment:** ChatGPT desktop app, reviewing my coding agent

**Start:** GPT-6 Astra · Medium

Locating code, explaining a function, a basic summary: a small inspection does not need the review default.

**Step up or change:** GPT-6 Astra · Extra high: when the request becomes a substantive correctness review.

**Step down:** No condition recorded.

## Reviewing substantial changes

**Environment:** ChatGPT desktop app, reviewing my coding agent

**Start:** GPT-6 Astra · Extra high

Cross-file behavior, architecture, requirements. Review is what I use the desktop app for, so Extra High is its standing default. Start with the change set; expand into dependencies only when warranted.

**Step up or change:** GPT-6 Astra · Max: when one specific hard issue is still unresolved after a checked attempt. Include the failed attempt, the evidence, and the exact issue.

**Step down:** GPT-6 Astra · Medium: for a small inspection, or bounded follow-through after the review.

## Visual review of an interface

**Environment:** ChatGPT desktop app, reviewing my coding agent

**Start:** GPT-6 Astra · Extra high

Code inspection alone cannot tell whether a design works visually. With screenshots or the running interface in front of the reviewer.

**Step up or change:** No condition recorded.

**Step down:** No condition recorded.

## Routine implementation

**Environment:** Claude Code in VS Code

**Start:** Claude Opus 5 · Medium

Familiar patterns and scoped fixes rarely need more.

**Step up or change:** Claude Opus 5 · High: when dependencies are unclear, reasoning is shallow, or fixes fail.

**Step down:** No condition recorded.

## Difficult implementation

**Environment:** Claude Code in VS Code

**Start:** Claude Opus 5 · High

High is the vendor’s starting point on Opus 5. Extra High is justified by the work, never a standing default.

**Step up or change:** Claude Opus 5 · Extra high: only if the specific problem remains unresolved.

**Step down:** No condition recorded.

## Substantial features, nuanced design

**Environment:** Claude Code in VS Code

**Start:** Claude Fable 5.1 · High

Many interacting requirements need the planning High buys.

**Step up or change:** No condition recorded.

**Step down:** Claude Fable 5.1 · Medium: for mechanical follow-through once the decisions are settled.

## Architecture, migrations, hard debugging

**Environment:** Claude Code in VS Code

**Start:** Claude Fable 5.1 · Extra high

Broad dependency changes and hard bugs are where I spend Extra High: the vendor’s setting for capability-sensitive, long-horizon work.

**Step up or change:** Claude Fable 5.1 · Max: for one clearly defined frontier problem after a checked attempt.

**Step down:** Claude Fable 5.1 · High: once the problem is understood and bounded.
